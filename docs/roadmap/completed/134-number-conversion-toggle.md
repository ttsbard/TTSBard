# ROADMAP-134 — Отключаемое преобразование чисел в слова

## Цель

Дать пользователю возможность отключать встроенное преобразование чисел
в русские слова перед синтезом речи.

## Согласованный интерфейс

Во вкладке «Настройки → Редактор» сразу после настройки шрифтов и перед
«Быстрым редактором» расположить отдельную компактную карточку без заголовка.
В ней — галочка «Преобразовывать числа в слова» и короткий пример
«Перед озвучкой: «123» → «сто двадцать три»».
Использовать существующие стили карточек и checkbox, как во вкладке AI.
Не добавлять упоминание AI в эту карточку.

## Поведение

- По умолчанию включено, в том числе при чтении старых настроек без нового поля.
- Выбор сохраняется между запусками; ошибка сохранения не оставляет ложное состояние UI.
- При отключении встроенный этап преобразования чисел пропускается во всех
  путях синтеза, включая входящие сообщения. Настройка фиксируется в snapshot
  запроса, чтобы очередь не меняла поведение задним числом.
- Подстановки по словарям, AI-коррекция, ударения и маршрутизация сохраняют
  существующее поведение. AI может преобразовывать числа по своему промпту.
- Алгоритм преобразования чисел не расширяется: дроби, даты и время не входят в scope.

## Критерии готовности

- Проверены значения по умолчанию, сохранение false и true, отключение
  преобразования в pipeline и сохранение подстановок.
- Локализация RU/EN и пользовательская документация отражают настройку.
- Выполнены frontend build, релевантные тесты и Rust check через Windows-обёртку.
- Проверены расположение карточки, обе темы и узкая ширина; непроверенные
  native-сценарии явно отмечены в локальном отчёте.
- Ведущий агент независимо проверил scoped diff и результаты команд.

## Outcome

В «Настройки → Редактор» появился переключатель преобразования чисел
перед озвучкой. Настройка включена по умолчанию и для старых файлов настроек,
сохраняется между запусками и входит в snapshot запроса, включая входящие
сообщения. Преобразование чисел можно отключить независимо от подстановок
и остальных этапов обработки текста.

Реализация вошла в `v1.6.2`. Проверены целевые Rust- и frontend-тесты,
frontend build и контракты. Полная ручная матрица Tauri с обеими темами,
узким окном, увеличенным шрифтом, масштабом Windows и проверкой после
перезапуска остаётся открытой.
