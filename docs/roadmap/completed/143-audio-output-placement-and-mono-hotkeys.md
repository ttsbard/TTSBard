# Расположение аудиовыходов и горячие клавиши в «Моно»

## Контекст

Продолжение [ROADMAP-142](../completed/142-audio-output-toggles.md).
Пользователь обнаружил: назначенный Ctrl+P переключает выход в компактном
режиме, но в «Моно» вызывает печать. В текущем коде обработчик принадлежит
OutputControlsGroup внутри условного заголовка App; при переходе в «Моно»
компонент удаляется вместе с listener. Это установленная причина по исходникам;
сценарий печати сообщён пользователем, native-воспроизведение пока не выполнено.

## Цель и контракт

- В «Настройки → Общие» добавить отдельную секцию «Состояние аудиовыходов» с выбором
  расположения группы: «В заголовке окна» или «Под редактором».
- По умолчанию показывать под редактором; выбранное расположение сохраняется между
  запусками. Не дублировать группу в двух местах. Настройка меняет размещение,
  а не область действия выходов или клавиш.
- Под редактором группа доступна на поверхности ввода; в заголовке — на
  разделах основного окна. В «Моно» не добавлять панель только ради этого фикса.
- Обработчик принадлежит основному окну и живёт независимо от заголовка,
  текущего раздела, расположения группы и normal/compact/mono.
- Назначенный и включённый Ctrl+P в активном основном окне переключает выход
  один раз и подавляет стандартную печать. Удержание не переключает по кругу.
  Учитывать фокус редактора/полей, IME, запись сочетаний и exact modifiers.
- Действия не становятся системными глобальными shortcut и не добавляются в
  отдельное окно SoundPanel. Назначения сохраняются.
- Не менять принятую модель: общее включение/выключение выхода TTSBard для речи
  и SoundPanel, немедленное прекращение подачи, без нового mute-состояния.
- Disabled, подсказки без inline-текста, кэш списка без мигания и отсутствие
  отдельной AI-кнопки сохраняются. Меню раскрывать внутрь окна: в шапке вниз,
  под редактором вверх.

## План

1. Отделить основной controller/listener от условно отображаемой группы;
   сохранять одну регистрацию и один источник состояния при смене режима.
2. Добавить сохраняемую настройку расположения в секцию общих настроек,
   переиспользовать существующий UI и его disabled/device guards.
3. Подключить выбранное размещение без дублирования listener/controller;
   при переключении режима или позиции не сбрасывать включённость выходов.
4. Regression: Ctrl+P в mono/editor/input без печати, однократность, recording,
   переключение режимов/позиции, сохранение выбора и default/fallback.
5. Обновить UI map и пользовательскую инструкцию RU/EN; проверить сборку,
   локализации, документы, обе темы и узкое окно в native.

## Реализованный результат и проверки

Добавлена секция «Состояние аудиовыходов» в общих настройках: заголовок/под редактором,
по умолчанию под редактором; выбор сохраняется как локальное UI-предпочтение.
При ошибке сохранения остаётся прежнее значение и показывается сообщение.
Группа отображается только в выбранном месте, а root controller и capture
listener живут независимо от её видимости. При окончательном App unmount
listener и detached scope освобождаются; новый App получает свой контекст.
Назначенный Ctrl+P работает в normal/compact/mono, отменяет печать, повтор
потребляется без повторного переключения. Старые helpers проверки устройств
и цели VBAN переиспользуются; audio enabled и SoundPanel не менялись.

Независимый итоговый прогон: 104 frontend test files / 2137 tests passed;
production build, check:locales (1565 keys), docs check (300 Markdown / 28 пар)
и diff check прошли. Тестируется реальный root mode shell и remount с другими
settings/device/bindings, а не только отдельная кнопка. Native Tauri/реальные
устройства/обе темы/узкая ширина пока not checked. Статус in_progress сохраняется
до приёмки; коммит не создавался.

Секция настроек переименована в «Состояние аудиовыходов» и расположена после кнопок дополнительных окон в заголовке, перед секцией папок.

### Результат исправлений

- IPC dispatch содержит литеральные команды; check:ipc проходит без обхода checker.
- Общий guard записи учитывает независимых владельцев HotkeysPanel и InterceptPanel,
  включая отложенный старт, отмену, ошибку и unmount. Записываемая комбинация
  не переключает выход. IME-события не потребляются; повтор Ctrl+P по-прежнему
  подавляет печать без повторного переключения.
- Для titlebar восстановлены отступ и слой меню 1200. Popover адаптивно ограничен
  границами viewport, пересчитывается при resize и смене подписей, очищает listener
  и игнорирует отложенный расчёт после закрытия.
- Вычисляемое состояние собрано в одном блоке controller scope; подтверждённой
  утечки computed не установлено. Удалены дублирующие начальные запросы устройств.
  Новый тест монтирует реальный InputPanel и проверяет up/compact/incoming/mono.
- SoundPanel, очередь речи, replay/history/restore сохраняют допустимую конфигурацию
  микрофона независимо от временного выключателя. Живое состояние выхода проверяется
  при старте элемента в обе стороны; устройство и gain остаются из снимка очереди.
  Явный запрет mic/preview сохраняется, оборванный текущий звук не возобновляется.
  Ранний отказ генерации при всех выключенных выходах остаётся прежним.
