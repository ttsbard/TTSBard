# Ручная настройка таймингов Silero

Время ожидания ответа синтеза Silero можно настроить прямо в интерфейсе: в карточке **TTS → Silero Bot** нажмите на иконку шестерёнки **«[⚙]»** в строке прокси и введите нужное количество секунд.

Также таймауты и задержки можно задавать вручную в `settings.json`.

## Где находится `settings.json`

Откройте **Настройки → Общие → Папки** и нажмите **«Открыть»** у
**«Конфигурация»**. Файл настроек — `settings.json` в открывшейся папке.

Windows: `%APPDATA%\ttsbard\settings.json`

Например: `C:\Users\<Имя>\AppData\Roaming\ttsbard\settings.json`

## Доступные параметры

Все параметры находятся в разделе `tts.telegram`, значения указываются в
миллисекундах.

| Ключ | По умолчанию | Диапазон | Назначение |
|---|---|---|---|
| `synthesis_response_timeout_ms` | `60000` | от `1000` (без верхнего лимита) | Ожидание ответа Silero после отправки текста |
| `download_retry_delay_ms` | `1000` | `100`…`10000` | Пауза перед повторной попыткой скачивания |

## Пример

```json
{
  "tts": {
    "telegram": {
      "synthesis_response_timeout_ms": 60000,
      "download_retry_delay_ms": 1000
    }
  }
}
```

Поля можно добавлять по одному — отсутствующие получат значения по умолчанию.

## Нормализация значений

Значения ниже минимума автоматически обрезаются: например, `synthesis_response_timeout_ms: 0` превратится в `1000`. У таймаута синтеза верхний предел отсутствует. Для `download_retry_delay_ms` значение `99999` превратится в `10000`.

## Отмена ожидания ответа

Отмена фразы во время генерации прекращает ожидание в приложении и освобождает
очередь для следующей фразы без ожидания таймаута. Уже отправленный запрос
остаётся у Telegram-бота. Запоздалое аудио принимается только при совпадении
ответа с исходным сообщением, поэтому аудио отменённой фразы не подменяет
результат следующей. Это не ускоряет обработку на стороне бота.

## Применение изменений

- При изменении времени ожидания через интерфейс новое значение **применяется сразу** к следующим озвучиваемым фразам.
- При ручном редактировании `settings.json` изменения вступают в силу после **перезапуска приложения**.
